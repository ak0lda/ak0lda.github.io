Характер

SYS.01

Сайт выглядит как панель инженерной системы: тёмный экран, сетка, тонкие линии, моноширинные метки и один яркий оранжевый сигнал. Он должен вызывать ощущение точности и надёжности, а не «креативного агентства».

Графит, а не чёрный

Фон #141313 с едва заметным тёплым оттенком. Чистый #000 не используется нигде.

Один акцент

Электрический оранжевый отмечает только главное: активный пункт, ключевую цифру, точку статуса, главную кнопку.

Язык терминала

Метки набраны моноширинным шрифтом капслоком: [ 01 ], SYS.02, МОДУЛЬ.01.

Линии вместо теней

Границы 1px, сетки с промежутком 1px, малые скругления. Без теней, градиентов, стекла и 3D.

Факты вместо картинок

Вместо иллюстраций работают цифры: «668 тестов», «−72% RAM». Стоковые фото и маскоты не используются.

Текущие знаки

SYS.05

Логотипа пока нет. На сайте используются три разных знака, и единой системы между ними нет.

Фавикон < >

Оранжевые угловые скобки на графитовой плитке со скруглением.

REF_DEVREF_DEV
Словесный знак REF_DEV

В шапке сайта набран Manrope, на обложке для соцсетей — моноширинным шрифтом в рамке.

{ }
Фигурные скобки { }

Декоративный глиф на обложке и на главной странице (иконка data_object).

Открытый вопрос для дизайнера

Какой знак развивать: угловые скобки < >, фигурные { } или букву/монограмму из REF_DEV? Предложите 2–3 направления. Выбранный знак заменит все три текущих.

ТЗ на логотип

SYS.06

01Что обозначаем

  • Личный бренд разработчика: REF_DEV (псевдоним) и Илья Тицкий.
  • Услуги: веб- и десктоп-приложения, автоматизация, Telegram-боты.
  • Клиенты: малый бизнес и заказчики на биржах. Важно ощущение надёжного инженера.

02Состав

  • Знак (символ) отдельно.
  • Словесная часть REF_DEV.
  • Горизонтальная связка: знак + REF_DEV.
  • По желанию: вариант с «Илья Тицкий · Fullstack».

03Где будет жить

  • Фавикон 16 и 32 px: знак должен читаться без мелких деталей.
  • Аватар на Kwork, FL.ru, Upwork, Habr, в Telegram и GitHub: круглая обрезка.
  • Шапка сайта на графитовом фоне.
  • Карточки проектов и обложка 1200×630.

04Цвет и шрифт

  • Только графит #141313, оранжевый #FF5F1F и светлый #E6E1E1.
  • Словесная часть на базе JetBrains Mono или Manrope, допускается доработка.
  • Нужна версия для светлого фона: страницы бирж в основном белые.
  • Нужна одноцветная версия: только графит и только белый.

05Что сдать

  • SVG (векторы, текст в кривых) для всех вариантов.
  • PNG с прозрачностью: 512 и 1024 px.
  • Аватар 1024×1024 на графитовом фоне.
  • Фавикон: SVG и PNG 32×32, 180×180.
  • Тёмная, светлая и одноцветная версии.

06Чего избегать

  • Градиенты, тени, объём, «стекло».
  • Новые цвета, особенно синий и фиолетовый «как у всех IT».
  • Маскоты, ноутбуки, шестерёнки, ракеты.
  • Готовая иконка «</>» из стоков без доработки.
  • Зелёный #34D399: это только статус на сайте.

Направление для светлого и тёмного фона (предложение, а не готовый знак)

REF_DEV
REF_DEV

На белом фоне текст набирается графитом #141313, оранжевый остаётся только в знаке и акцентах. Контраст оранжевого на белом ≈ 3:1, поэтому мелкий текст оранжевым на белом не набирается.

Карточки проектов для бирж

SYS.07

Четыре проекта с сайта, каждый на русском и английском. Карточка повторяет стиль сайта: графитовая рамка, крупный заголовок Manrope, три ключевые цифры в сетке и чипы стека.

  1. Знак бренда слева вверху, индекс SYS.0X справа.
  2. Надзаголовок оранжевым моно: номер и тип проекта.

  4. Одна фраза о сути, с оранжевой линией слева.
  5. Три цифры только из реального кейса; последняя оранжевая.
  6. До четырёх чипов стека и адрес сайта внизу.

Весь текст и цифры лежат внутри центрального квадрата, поэтому карточка не теряет смысла, если биржа обрежет превью до квадрата. Upwork рекомендует горизонтальные превью 4:3 (1000×750 и больше) по ответам поддержки. Официальный размер для Kwork найти не удалось: перед загрузкой проверьте, как площадка обрезает превью.

Исходники карточек лежат в репозитории: marketing/cards/build.py. Когда появится логотип, замените строку BRAND_HTML на картинку и перезапустите скрипт: все восемь PNG пересоберутся.
