# ak0lda.github.io — портфолио Ильи Витальевича

Сайт: https://ak0lda.github.io/

Статичный сайт на чистом HTML + Tailwind CSS (собранный заранее). Без фреймворков и сборщиков: GitHub Pages отдаёт файлы как есть.

## Структура

```
CV_Blog/
├─ index.html            ← Home       → /
├─ scope/index.html      ← Scope      → /scope/
├─ stack/index.html      ← Stack      → /stack/
├─ work/index.html       ← Work       → /work/
├─ ping/index.html       ← Contacts   → /ping/
├─ en/                   ← английская версия тех же страниц (/en/, /en/scope/ …)
├─ 404.html              ← страница ошибки (GitHub Pages подхватывает сам; для адресов /en/… переводится скриптом)
├─ assets/
│  ├─ css/styles.css     ← СОБРАННЫЙ CSS, руками не править
│  ├─ js/main.js         ← мобильное меню, часы на 404
│  ├─ js/contacts.js     ← ссылки на контакты (GgiitHub, Telegram, LinkedIn, email)
│  ├─ img/favicon.svg
│  └─ cv/                ← сюда положить PDF резюме
├─ src/input.css         ← исходник стилей (общие классы, анимации)
├─ tailwind.config.js    ← единая дизайн-система (цвета, шрифты, отступы)
└─ .nojekyll             ← отключает обработку Jekyll на GitHub Pages
```

Все ссылки между страницами относительные (`./scope/`, `../work/`), поэтому сайт работает и в корне домена, и в подпапке репозитория.

## Языки

Русская версия лежит в корне, английская — в `en/` с той же структурой папок. Переключатель `[ RU / EN ]` в шапке каждой страницы ведёт на ту же страницу на другом языке. Страницы независимы: правите текст в русской версии — не забудьте поправить и английскую (и наоборот).

## Цвета

Используются только цвета из `tailwind.config.js` (`theme.colors`). Встроенная палитра Tailwind (`neutral-*`, `white`, `black`, `emerald-*` и т. п.) отключена, а цвета прямо в классах (`bg-[#ff5f1f]`) не используем. Нужен новый цвет — добавьте токен в конфиг и пересоберите CSS.

То же с размерами текста: шкала Tailwind (`text-sm`, `text-xl`, `text-8xl` …) и размеры прямо в классах (`text-[26px]`) отключены, доступны только токены из `theme.fontSize` — включая размеры иконок (`icon-*`) и крупных декоративных глифов (`glyph-*`).
